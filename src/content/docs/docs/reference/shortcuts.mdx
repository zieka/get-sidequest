---
title: Shortcuts Cheat Sheet
description: Complete reference of all Sidequest keyboard shortcuts.
---

Every keyboard shortcut available in Sidequest, organized by category. All shortcuts use the **Cmd** key.

Press **Cmd+/** inside the app to open the built-in shortcuts overlay.

## Navigation

| Shortcut | Action | Context |
|----------|--------|---------|
| Cmd+[ | Navigate to previous quest | Global |
| Cmd+] | Navigate to next quest | Global |
| Cmd+Shift+P | Open command palette | Global |

## Settings and Help

| Shortcut | Action | Context |
|----------|--------|---------|
| Cmd+, | Open settings | Global |
| Cmd+/ | Show keyboard shortcuts | Global |
| Cmd+R | Reload window | Global |

## Panel Toggles

| Shortcut | Action | Context |
|----------|--------|---------|
| Cmd+1 | Toggle Workspaces sidebar | Global |
| Cmd+2 | Toggle Quest Log | Global |
| Cmd+3 | Toggle Terminal panel | Global |
| Cmd+4 | Toggle Changes panel | Global |
| Cmd+5 | Toggle first visible extension (Live Stats by default) | Global |
| Cmd+6 | Toggle second visible extension (Toolkit by default) | Global |
| Cmd+7 | Toggle third visible extension (Council by default) | Global |

Extension shortcuts (Cmd+5 and above) map to extensions in the order they appear in the bottom toolbar. Reorder or hide extensions in **Settings > Extensions** (or right-click the toolbar and choose **Customize Bottom Bar...**) to change the mapping.

## Zoom

| Shortcut | Action | Context |
|----------|--------|---------|
| Cmd+= | Zoom in (whole interface, including the terminal) | Global |
| Cmd+- | Zoom out | Global |

## Changes Panel

| Shortcut | Action | Context |
|----------|--------|---------|
| Cmd+F / Ctrl+F | Find in diff | Changes panel |
| Enter / Shift+Enter | Next / previous match | Find bar |
| Esc | Close find bar, or clear the file filter | Changes panel |

## Terminal

| Shortcut | Action | Context |
|----------|--------|---------|
| Cmd+C | Copy selection (passes through when nothing is selected) | Terminal |
| Cmd+V | Paste (long pastes become a temp file path) | Terminal |
| Ctrl+V | Literal ^V, for Claude Code image paste | Terminal |
| Cmd+1–9, Cmd+[, Cmd+], Cmd+=, Cmd+-, Cmd+/, Cmd+,, Cmd+R, Cmd+Shift+P | Pass through to Sidequest | Terminal |

## Editing (Menu Bar)

Standard macOS edit shortcuts available via the Edit menu:

| Shortcut | Action | Context |
|----------|--------|---------|
| Cmd+Z | Undo | Text fields |
| Cmd+Shift+Z | Redo | Text fields |
| Cmd+X | Cut | Text fields |
| Cmd+C | Copy | Text fields |
| Cmd+V | Paste | Text fields |
| Cmd+A | Select All | Text fields |

## Window

| Shortcut | Action | Context |
|----------|--------|---------|
| Cmd+M | Minimize window | Global |
| Cmd+W | Close window | Global |
| Ctrl+Cmd+F | Toggle fullscreen | Global |

## Command Palette

These actions are available from within the command palette (Cmd+Shift+P):

| Action | How |
|--------|-----|
| Search quests | Type quest name or prompt text |
| Search files | Type **>** then a filename |
| Jump to quest | Select an active quest |
| Edit quest | Select a backlog quest |
| Open project | Select a project row |
| Create quest | **Q** on a highlighted project |
| Open in editor | **E** on a highlighted active quest |
| Activate backlog quest | **A** on a highlighted backlog quest |
| Slash commands | Type **/** then `terminal`, `editor` or `remote`; **Tab** completes |

## Dialogs

| Shortcut | Action | Context |
|----------|--------|---------|
| Enter | Create the quest | Create Quest prompt |
| Shift+Enter | New line in the prompt | Create Quest prompt |
| / | Autocomplete skills, commands and agents | Create Quest prompt |
| K / X / → | Keep / Archive or Delete / Skip | Review old journals |
| Option (hold) | Expand Open in Editor / Terminal into submenus | Context menus |
| Space or Enter | Pick up / drop a quest with the keyboard | Supervisors board |

## Bottom Toolbar Shortcut Discovery

Hold the **Cmd** key for approximately one second to reveal shortcut labels above each panel toggle button, the extension buttons and the Settings button in the bottom toolbar. Release Cmd to hide them.
