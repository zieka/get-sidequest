Sidequest runs agents you have already installed and logged into on your machine. On first launch the **Welcome Bot** checks for every agent and tool, picks a default agent you have, and offers to install anything that is missing.

## Dependencies

The Welcome Bot lists them in three groups:

| Group | Tool | Purpose |
|-------|------|---------|
| **Agents** | Claude Code, Gemini CLI, Codex CLI, Copilot CLI, OpenCode | Run your quests. You need at least one. |
| **Foundations** | **git**, **tmux** | Required. git keeps each quest in its own worktree; tmux keeps sessions alive in the background. |
| **Extras** | **GitHub CLI (gh)** | Optional but recommended -- enables issue browsing, PR badges, Review quests and cloning private repos |
| | **Apple Foundation Models** (macOS) | Optional. Names quest branches on-device for free, before falling back to Claude. Listed only when Apple's `fm` tool is present. |

Install **Claude Code** even if you mostly run other agents: journals, handoffs, Council summaries and the smart router all use it. Supervisors can run on Claude Code, Codex CLI, Copilot CLI or OpenCode.

### Agents

All agents install through npm. Install and authenticate whichever you want to use, then point Sidequest at them in **Settings > Agent** if they are not found automatically:

| Agent | Binary | Install |
|-------|--------|---------|
| Claude Code | `claude` | `npm install -g @anthropic-ai/claude-code` |
| Gemini CLI | `gemini` | `npm install -g @google/gemini-cli` |
| Codex CLI | `codex` | `npm install -g @openai/codex` |
| Copilot CLI | `copilot` | `npm install -g @github/copilot` |
| OpenCode | `opencode` | `npm install -g opencode-ai` |

See [Agents and Models](/get-sidequest/docs/guides/agents-and-models/) for what each agent supports inside Sidequest.

## Installing Dependencies

### macOS (Homebrew)

```bash
# Claude Code CLI (requires Node.js)
npm install -g @anthropic-ai/claude-code

# tmux, git, and GitHub CLI
brew install tmux git gh
```

If you don't have Homebrew, install it first:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

If you don't have Node.js (required for Claude Code), install it from [nodejs.org](https://nodejs.org) or via Homebrew:

```bash
brew install node
```

### Linux (apt)

```bash
# Claude Code CLI (requires Node.js)
npm install -g @anthropic-ai/claude-code

# tmux, git, and GitHub CLI
sudo apt-get install -y tmux git gh
```

### Linux (dnf)

```bash
npm install -g @anthropic-ai/claude-code
sudo dnf install -y tmux git gh
```

### Linux (pacman)

```bash
npm install -g @anthropic-ai/claude-code
sudo pacman -S --noconfirm tmux git gh
```

## Welcome Bot

When you launch Sidequest for the first time, the Welcome Bot scans your machine:

1. Each tool shows its version and a check mark when found.
2. Pick the agent that runs new quests; it is marked **Default**. The Welcome Bot keeps your current default if it is installed, otherwise it picks the first installed agent in the list. Change it later in **Settings > Agent**.
3. For a missing tool, click **Install** when its package manager is present (npm for agents; Homebrew on macOS; apt, dnf or pacman on Linux). Otherwise the row names what is missing (for example **Needs Node.js**) and offers **Copy command**.
4. If Apple Foundation Models shows **License not agreed yet**, copy `sudo fm license` and run it in a terminal.
5. Click **Check again** to rescan, then **Start questing**. If git or tmux is missing, or no agent is installed, the button reads **Continue anyway**.

Quests cannot run until git and tmux are installed.

You can re-run the Welcome Bot at any time from **Settings > General > Setup Guide > Run Again**.

## Path Resolution

Sidequest resolves tool paths using your login shell's environment. This means tools installed via version managers like nvm, mise, fnm, or volta are detected automatically.

If Sidequest can't find a tool (common when launched from Finder on macOS, which has a minimal PATH), it also checks well-known install locations:

- `/opt/homebrew/bin/` (Homebrew on Apple Silicon)
- `/usr/local/bin/` (Homebrew on Intel / manual installs)
- `/usr/bin/` (system packages)

### Custom Tool Paths

If auto-discovery doesn't find your tools, set explicit paths in **Settings**: git and tmux under **Tools**, and each agent's CLI under **Agent**. Leave a field empty to revert to auto-discovery. Each agent field shows **Detected** or **Not found** so you can confirm the path works.

## What Sidequest installs for you

On every launch Sidequest refreshes a few files of its own:

- `~/.sidequest/bin/sidequest` and `~/.sidequest/bin/sidequest-journal` -- command-line tools that agents (and you) can use. See [Sidequest CLI](/get-sidequest/docs/advanced/cli/).
- `~/.claude/skills/sidequest/SKILL.md` and `~/.claude/skills/sidequest-journal/SKILL.md` -- Claude Code skills that teach the agent how to use those tools. They are rewritten at every launch, so edit the extended prompts instead of these files.
- `~/.sidequest/skills/sidequest-supervisor.md` -- the supervisor's standing instructions.
- A Claude Code **Stop hook** (once you enable notifications in **Settings > Notifications**) so Sidequest knows when a session is waiting for you.

Each Claude Code quest on this machine also starts with a statusline, `~/.sidequest/hooks/statusline.sh`, that records Claude's `/usage` counter for [Live Stats](/get-sidequest/docs/guides/usage-dashboard/#live-stats) and then runs your own statusline.

## Verifying Your Setup

To verify tools are working from your terminal:

```bash
claude --version
tmux -V
git --version
gh --version
```
