Welcome to the Sidequest documentation. Sidequest runs coding agents -- Claude Code, Gemini CLI, Codex CLI, Copilot CLI and OpenCode -- as **quests** on a per-project board, isolates each one in its own git worktree, and lets a **supervisor** agent keep the board moving while you are away.

This documentation describes Sidequest **0.83**.

## What changed recently

New since 0.75:

- **Sagas replace recurring quests.** Draw a workflow of quest, condition, wait, human-input, command and other steps, start it on a schedule, a new pull request or issue, or by hand, and watch each run on its graph. Existing recurring quests are converted on first launch.
- **Remote machines.** A quest can run its agent and checkout on an ssh host, Docker container, devpod.sh or Coder workspace, chosen per workspace, project or quest.
- **The `sidequest` CLI covers the whole board**: quests, supervisors, Sagas, projects, settings, remotes, accounts and disk cleanup.
- **Supervisors run on Codex, Copilot or OpenCode** as well as Claude Code, act through the CLI, and wake as soon as work is assigned. The Supervisors board hides the Unassigned pool until you open it.
- **Shell quests** open a plain terminal with no agent.
- **Diff comments.** Comment on lines in the Changes panel and send the notes to the quest's agent.
- **Workspace defaults** for notification sound, review template, **Run on** and **Launch Template**, which projects inherit.
- **Codex** quests run without approval prompts by default (opt into **Approve for Me**), with model and effort pickers.
- New quests start from the freshly fetched `origin` branch, and branch names come from Apple's on-device model when it is installed and licensed.
- A **Welcome Bot** first-run guide that detects every agent on your machine.

Earlier, 0.75 brought:

- **Quest types were renamed.** "Changes" is now **Worktree** and "Research" is now **Current Branch**. The behaviour is unchanged.
- **Supervisors are cross-repo groups**, not a per-project toggle. Open them from the robot button in the bottom bar.
- **Five agents.** Gemini CLI, Codex CLI, Copilot CLI and OpenCode can run quests alongside Claude Code.
- **Smart model router** picks a model and effort per quest; **profiles** let you run quests under different Claude accounts.
- **Journals are written automatically** when a quest completes, and agents search them with `sidequest-journal`.
- **Supervisors remember.** A restarted supervisor resumes its previous conversation and keeps a notes file, and each project can name a **default supervisor** for new quests.
- **Home quests**, the **Active Quests** timeline, **token budgets**, **GitHub issue browsing**, cloning projects from a URL, and more.
