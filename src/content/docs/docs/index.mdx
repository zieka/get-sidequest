Welcome to the Sidequest documentation. Sidequest runs coding agents -- Claude Code, Gemini CLI, Codex CLI, Copilot CLI and OpenCode -- as **quests** on a per-project board, isolates each one in its own git worktree, and lets a **supervisor** agent keep the board moving while you are away.

This documentation describes Sidequest **0.75**, plus two supervisor changes merged after that release: a default supervisor per project and supervisors that resume their session on restart.

## What changed recently

If you last used Sidequest in the spring, the biggest changes are:

- **Quest types were renamed.** "Changes" is now **Worktree** and "Research" is now **Current Branch**. The behaviour is unchanged.
- **Supervisors are cross-repo groups**, not a per-project toggle. Open them from the robot button in the bottom bar.
- **Five agents.** Gemini CLI, Codex CLI, Copilot CLI and OpenCode can run quests alongside Claude Code.
- **Smart model router** picks a model and effort per quest; **profiles** let you run quests under different Claude accounts.
- **Journals are written automatically** when a quest completes, and a `sidequest-journal` CLI lets agents search them.
- **Supervisors remember.** A restarted supervisor resumes its previous conversation and keeps a notes file, and each project can name a **default supervisor** for new quests.
- **Home quests**, the **Active Quests** timeline, **token budgets**, **GitHub issue browsing**, cloning projects from a URL, and more.
